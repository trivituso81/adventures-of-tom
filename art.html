Setup

Each generated image costs about $0.04 plus $0.01 per reference picture. Results stay on this device (last 5 per picture). UPLOAD MY OWN (beside GENERATE, on every picture) uses your own image instead: free, no key needed, and it goes through the same APPROVE or REJECT. For a sheet, keep the same grid layout a generated one has. APPROVE saves a picture and its prompt into the game's files on GitHub; REJECT saves your note for Claude. Both need the GitHub token.
