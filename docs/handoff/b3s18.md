Lessons for the next session:
- Push races are heavy now (several sessions and Actions push every few seconds). A slow step between `git fetch` and `git push` loses the race. What worked: commit the payload, then in one fast script fetch, `git checkout -B work origin/main`, `git cherry-pick -n <commit>`, take upstream for `data/build-history.js`, `engine/main.js`, `index.html`, `data/board.json`, redo the tag lines and the build stamp with a short script, `python3 tools/build_history.py add <TAG>`, re-apply the card edit, commit and push; run `tools/tag_check.py` and `board_check.py` after. A shallow clone makes `git rebase` replay everything, so cherry-pick instead. `git push` output containing "HEAD -> main" does not mean it landed (a rejection prints it too): compare `git rev-parse HEAD` with `origin/main` after a fetch.
- Another session's push can undo yours. Check `main` after a push (`git show origin/main:data/b3-story.js | grep chapters`) and again before you finish.
- `data/board.json` can arrive with merge conflict markers from another session; `python3 -c "import json;json.load(open('data/board.json'))"` before you build on it.
- The bonus chapter is the only part of the story with bespoke battle 2 boss code; read `docs/BATTLE3.md` before touching it.
