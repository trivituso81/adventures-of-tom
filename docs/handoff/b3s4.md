## Things the next stage should know

- A unit is built from a loadout: `b3PartyUnit` calls `b3Kit(id, b3FixLoadout(...))`. New unit fields: `vibe`, `pocket`, `lean`, `rank`, `pocketSkills`, `quirks`, `mods` (the Lean, same shape as a status's mods; `b3Mods` adds them), `counterInfo`, `hitSince`.
- `cfg.plain` exists only so the older rule tests keep their numbers. Do not use it in new tests, and do not give plain units anything new: a plain unit has no Trait and no Quirks by design, so writing the real Trait rows in stage 5 will not move a single older check.
- To make a Trait or Quirk work: add `on`, the listener fields and `effects` to its existing row and delete `soon:true`. `b3KitPassives` then puts it on the unit (the Trait when its Vibe is Main, a Quirk when it is in a slot). The data check runs `effects` only for rows without `soon`.
- To make a named Skill real: write its row and delete its `B3_SOON` line (the data check fails if it is in both). Its `slot` must match its place in the Vibe's `skills` (`s1`, `s2`, `cap`).
- `tools/b3-check-s2.js` has one test that swaps in a test `priority_boarding` row and puts the real one back. When stage 5 writes the real row that test still passes (it restores whatever was there).
- Rank 4 unlocks the Capstone. The Lab starts at Rank 2, and the screen test resets the Lab's book before every fight (`b3LabReset()` in `start()`), so writing the Capstones will not change the six hand-played fights. The simulator's default is Rank 2 as well (`--rank=4` to see Capstones).
- The simple player (`b3AutoScore`) now values a heal (HP it really gives back, more on someone under 35%, a little per debuff cleared). It has no score yet for a shield, a buff on an ally, or a Capstone's extras: add them as stage 5 writes those moves, or the simulator will never use them.
- Conditions and effect gates added: `bonus:{if:'tookHit'}`, `bonus:{counter:'<id>', add}`, an effect's `when:'cleansed'|'stripped'`. Target kind `family`. Effect target `lowestAlly`.
- The Vibes screen marks a row SOON while `built` is false (`b3Ladder`). Nothing else on the screen needs to change as rows become real.
- The pause menu's door lists the party only. Bench members keep their loadouts in the save all the same.
- Late joiners (spec section 1: a VP pool to split once) are not built. The first late joiner in the new battle is TNB or Nara (stage 9).
- Spoken lines: still none for any Battle 3 move (`line:null`), 21 moves waiting (architecture risk 8).
