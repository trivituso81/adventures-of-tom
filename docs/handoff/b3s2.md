## Things the next stage should know

- Beat order inside one action: `pre`, hit groups (numbers), `post`, reaction groups (`r0`, `r1`...), `end`. `b3EndTurn` now stamps `g:'end'`. A new op must still stamp `g:c.g`.
- A reaction is queued by a listener row with `react:true` and run by `b3RunReactions` after the action's effects, before `actionEnd`. Enemy counter acts (stage 3, "Points Off") should use the same queue so the screen needs nothing new.
- `b3DamageOp` has two paths: the move's own damage (swings, hit groups, intercepts) and an effect with its own `power` and `flavor` (no swing beat, beats stay in the current `g`).
- Intercepts live in `b3DamageOp`: an enemy's single-target hit is redirected before the swing beat. A Marked follow-up (stage 3) only has to go through `b3DamageOp` with its marked target to be intercepted.
- The `composure` op writes `c.ledger[foe key]`. Nothing reads it. Stage 3: pay it at `actionEnd` with the 3-pip cap, add Pet Peeve and Detonation pips (the Detonation rows already carry `pips`).
- A hazard trips in `b3FoeTurn` before the `act` beat, only on the turn the act fires (not on the wind-up turn). A fall that knocks the monster out ends its turn with no act.
- Statuses now need `desc`, `short` and `color` or the data check fails. `b3Carried(F,u)` builds the list the screen shows.
- A move with no hits shows its cost at once and its effects when the pose lands (`late` in `b3PlayMove`).
- A Skill with exactly one possible target fires without a target step (Wet-Floor Hazard, Suite Door Slide, Pick-Me-Up with one member down).
- `b3Skills(F,u)` takes the fight now. `b3SkillRows(u)` in the UI is the list without the Basic.
- Stat Leans are still not applied (stage 4). Rows default from the Lean already (`rowByLean`), and all four first Sig Vibes stand in Front.
- Spoken lines: still none for any Battle 3 move (`line:null`). 14 moves now wait for a line (architecture risk 8).
