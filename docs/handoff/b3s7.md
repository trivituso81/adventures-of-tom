## Things stage 8 should know

- Stage 8 is the clips stage: read `docs/BATTLE3.md` "Clips: facts for stage 8" first.
- `b3Preview` runs the real rules on a copy, so anything a new rule keeps outside `F` (a global, a timer) will leak into previews. Keep rules state inside `F`.
- Do not let a rules file read `F.preview` for anything but randomness: it is only for `b3Rand` and the crit roll in `b3-resolve.js`.
- Test sandbox rows from stage 7 are `t7_*`, deleted at the end of `tools/b3-check-s7.js`.
- Picture CSS gotcha: `.bp-ic .bi{width:100%;height:100%}` blows up any extra picture put inside a `.bp-ic`; give the wrapper an explicit pixel size (see `b3pStar`, `.b3p-ef`).
- A touch test must send `pointerdown` with `pointerType:'touch'` then click (`TAP` in `stage7`); a Playwright mouse click is a mouse.
- `unused_voice.py` check 4 shows 93 dialogue clips, the same on `origin/main` before this build. No voice lines were added.
