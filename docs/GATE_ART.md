# Gate art: the painted layer for closed entrances (gatelayer1, 2026-11-20)

Tom (11-20): "search through all instances in the overworld maps (not dungeons or building interiors) for blocked entrances like this and propose a more elegant solution. for example in this case, i propose a separate layer for door art and separate art for unlocked and locked doors, that get autogenerated in the art library. and they should never overlap the character."

## How it works

- A closed entrance is a map gate (`spec.gates[i]` in `data/maps-le.js`, `data/maps-la.js`, `data/bonus-nine-scoops.js`): tiles, a story condition (`cond`), a bump note. It blocks walking. It no longer draws anything itself.
- What the player sees is a painted picture on its own layer. `data/gate-art.js` (`GATE_ART`) lists the sites; a gate names its site with `art: '<site>'`. `engine/gate-art.js` draws it.
- Two states per site: `locked` (while any gate naming the site still matches its `cond`) and, for doors and gates that swing or lift, `open` (once none matches). A site with only `locked` shows the bare plate once unlocked.
- Never over a character: the picture is an item in `draw()`'s depth sort at the top edge of its rectangle, so anyone standing on or south of the rectangle (Tom, the followers, NPCs) is drawn after it. It is not a last pass any more.
- Pictures are made in ADMIN > ART LIBRARY > Props > Story gates (`tools/art-library/gate-prompts.js`, `node tools/art-library/gate-prompts.js` refreshes the gate entries and keeps approved ones). Approving an entry bakes `art/gates/<site>-<state>.webp` (`tools/sprite-bake/bake_gate_art.py`, run by art-bake) and rewrites `GATE_HAVE` in `data/gate-art.js`; the game only fetches pictures listed there, so a picture still waiting in the Library costs no request.

## Adding a site

1. Add the site to `GATE_ART` (map, rect in tiles, `fit`/`fill`, states) and `art: '<site>'` to its gate(s).
2. Add its entries to `GATES` in `gate-prompts.js` and run that file with node.
3. `python3 tools/gate_art_test.py --grid <site>` writes a gridded crop of the plate to read the rectangle from.
4. After Tom approves, the Action bakes it. By hand: `python3 tools/sprite-bake/bake_gate_art.py <site> <locked|open>` (needs the keyed `tools/sprite-bake/src/gate-<site>-<state>.png`, not committed).
5. `python3 tools/gate_art_test.py` (registry, states, depth order, pixel check in portrait and landscape). It must say ok.
