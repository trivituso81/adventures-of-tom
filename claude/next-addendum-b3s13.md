# Stage 14 facts (written by the b3s13 session, 2026-11-20)

Read after `claude/battle-build.md`. Where it and that file differ, this one wins until stage 14 folds it in.

| Fact | Detail |
|---|---|
| What stage 13 built | One data file per chapter: `data/b3-foes-ch08.js`, `ch09.js`, `ch10.js`, `ch11bonus.js`; formations in each; Lab fights `new45` to `new66` in `data/b3-lab.js`; statuses at the end of `data/b3-status.js`; checks in `tools/b3-check-s13.js` (registered in `tools/b3-sim.js`); browser part `stage13` in `tools/b3_test.py` (`s13a`, `s13b`, `s13c`, `s13`). |
| Where the numbers live | A monster's `hp` (`hp3`/`hp4` for a boss by party size), `atk`, `def`, `spd`, `pips` are in its `B3_FOES.<id>` row; an act's `power` and `recovery` are on the act. Statuses' sizes are in `data/b3-status.js`. Changing a number changes no rule; the check file asserts the bestiary's printed numbers, so a retuned row also needs its line in `tools/b3-check-s13.js` (and the earlier `b3-check-s11.js`, `s12.js`) changed in the same push, with the old value kept in the commit message. |
| Boss Lab fights | `new6` The Big One, `new16` The Big Shake, `new21` Old Iron-Gill, `new27` The Director's Cut, `new32` The Red Pen, `new38` Chairman Cheeks, `new44` The Unread, `new50` Old Ironbelly, `new56` The Mirrorball, `new62` The Last Call, `new66` Brain Freeze. Elite fights: `new5`, `new15` (Tar Pit Blob), `new20` (Snag), `new26`, `new31`, `new37`, `new43`, `new49`, `new55`, `new61`, `new65`. |
| Plain-player rounds now (stage 11 to 13) | Bosses: Big One 3.5, Big Shake 4.7, Iron-Gill 4.1, Director's Cut 4.4, Red Pen 5.8, Chairman Cheeks 3.3, Unread 5.1, Ironbelly 5.1, Mirrorball 3.8, Last Call 4.6, Brain Freeze 4.2 (target 5 to 7). Normal fights 0.7 to 3.5 rounds. Chapter 1 numbers also need re-measuring with Vibes at Rank 2 and Rank 5 (stage 5 to 6 notes in `claude/battle-build.md`). |
| Simulator | `node tools/b3-sim.js <fight> 100` (rounds to win, knock-outs, Breaks, moves used); `--rank=5`, `--rec`, `--swap=all`, `--foehp=3` change the family. The plain player rarely uses Support Skills and never casts the two Capstones in short fights, so a boss that is short for it may be longer for a human. |
| Browser test | `CHROMIUM=/usr/bin/google-chrome python3 tools/b3_test.py s13` takes about 12 minutes (portrait and landscape): start it with nohup in the background and poll the log. The earlier stages' parts (`s11`, `s12`) take about 16 minutes. Poke a boss's HP or speed only for the fight you test. |
| Seams added in stage 13 | Strip kind `shieldOrBuff` (removes a shield first, else a buff); targets `frontAllies`, `firstTarget`, `lowestOtherAlly`; act condition `allyHurt`. Described in `docs/BATTLE3.md` "What stage 13 holds". |
| Rules found | Elite wind-ups are usually Broken by the family's pips, so a browser test for an Elite checks the win only and the rule test covers the act. A foe's id must equal its old `MONSTERS[id]` id or the browser Lab fight crashes (the bonus ids gremlin, slushslug, conehead, brainfreeze exist in `data/bonus-nine-scoops.js`). `B3_HAZARDS` is a separate table after `B3_STATUS`: never put a status there. |
| Git | The upstream moves constantly. On a rebase conflict take upstream for `data/board.json`, `data/build-history.js`, `docs/CHANGES.md`, `index.html`, `engine/main.js` and the build-archive files, then re-apply your own lines (script tag, CHANGES entry, board edit), re-run `bump_tags.py`, `git add`, `GIT_EDITOR=true git rebase --continue`, and push with `git -c push.negotiate=true push origin HEAD:main`. |
| Not done on purpose | Pictures and clips for any stage 13 monster (all acts use the default animation), the chapter 8 to 10 story switch (stage 17), balance (stage 14). |
