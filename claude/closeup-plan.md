|---|---|---|
| WATCH | A painted plate with code-drawn or part-based animation that plays once; waits for one A press to start; A while playing skips to the end; A at the end continues. DONE (closeupWatch in engine/closeup.js; a def supplies build, frame(t), cues, captions) | Row 1 |
| PLACE | One object lowers onto a plate at a marked spot, the spot lights up; A to set it down. DONE as `closeupPlaceDef` | Row 2 |
| ORDERED groups | Items that are interchangeable share `group`; order lists the group. DONE (Row 4) | Row 4 |
| DIAL | Parts rotate about a center in steps (left and right turn, A confirms); a target position is the right answer. DONE (Row 6, closeup8) | Row 6 |
| LEVER | A part swings between two positions on A; an optional lamp flares at the end. DONE (Row 7, closeup9) | Row 7 |
| SWITCH | A toggle switch on a box with a lamp that stays lit (right) or sparks and flips back (wrong). DONE as `closeupSwitch` (Row 8, closeup10); a variant inside LEVER's hooks, not a separate input path | Row 8 |
