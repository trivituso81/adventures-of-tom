## The method that worked (Tom approved the chapter 2 result)
1. Idea first. For each scene write one sentence: what each person wants and the one comic situation. No lines yet.
2. Write the lines from the move mechanisms in the settings, not from the examples.
3. Three tests on every joke line (claude/story-line-rules.md): could another character say it unchanged; who or what is the speaker caring about; does it contain a word for the speaker's own trait.
4. Facts arrive inside the back and forth, never as an announcement.
5. Copy check: no four words in a row shared with bank.txt, the old game scenes or earlier drafts, except plain story facts and lines Tom asked to keep.
6. Tone tags for every line in Tom's style (bracket tags where the tone changes, capitals on the stressed word, [punchline]; TNB always mellow and lower case).
7. When Tom flags a line, throw it away and rewrite it from what the character wants. Never edit the flagged words. If he flags the same kind of thing twice, stop and explain the cause before writing more.

```python
import re,os
def w(t): return re.findall(r"[a-z']+",t.lower())
def sh(t,n):
    x=w(t); return {" ".join(x[i:i+n]) for i in range(len(x)-n+1)}
srcs={"stored lines":open("bank.txt").read(),"earlier drafts":open("old.txt").read()}
p="adventures-of-tom/data/scenes.js"
if os.path.exists(p): srcs["old game scenes"]=open(p,errors="ignore").read()
scene=open("scene.txt").read().strip().split("\n")
for name,t in srcs.items():
    S=sh(t,4); hits=[(i+1,g) for i,l in enumerate(scene) for g in sh(l,4) if g in S]
    print(name,"| 4 words in a row:",len(hits),hits[:40])
```
