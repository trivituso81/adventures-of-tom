# Story engine capabilities (draft 2026-11-17, from claude/next.md; VERIFY against the repo CLAUDE.md and docs before relying on it)

Writers use only these in action lines. Anything else is tagged NEW ART with a cost.

| Can do today | Notes |
|---|---|
| Speech boxes with a face, per speaker, per mood | Talking poses (4 per main character) and mood poses |
| Silent page ("...") | Used for a quiet beat |
| Walk, place, face, stage the party around a person or object | Scene staging, camera zoom on the party and the person the scene is about |
| Painted close-up of an object (coin, block) | Close-up screens, used when a coin goes into a block |
| Text messages as lines | Used for texts |
| Fights, bosses, shrink back, monsters per area | Existing |
| Areas and rooms as painted plates | A new painted variant (purple sky) is new art |
| Narrator line | Only for what cannot be shown; Tom prefers action lines |

| Not supported (NEW ART or engine work) | Examples |
|---|---|
| Held-prop animations | A can held up to glass, a mug tipping |
| Custom pet animations | Nara sit, paw, sneeze, catch a coin, lean (listed as new frames in story-ch02.md) |
| Environmental effects | Smog rolling down a street seen through a window, the hill's sneeze |
