| Git (learned 2026-11-20) | Never `git fetch --depth=1` into a clone that has local commits: it loses the merge base and a rebase replays hundreds of commits into conflicts. Use `git fetch --depth=50 origin main` then `git rebase origin/main`. If it happens, `git rebase --abort`, push nothing, and reset only if all your work is already on origin. On a real conflict take upstream for `data/board.json`, `data/build-history.js`, `docs/CHANGES.md`, `index.html`, `engine/main.js` and the build-archive files, re-apply your own lines, re-run `bump_tags.py`, and push with `git -c push.negotiate=true push origin HEAD:main`. |
