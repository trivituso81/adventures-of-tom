# Tom's line edits (the humor guide)

Newest first. Every edit Tom makes to a built line goes here as a before and after, with the pattern it shows. This is raw evidence, not paraphrase: read the table before writing or revising any dialogue, and score every new line against it ("would Tom cut this?"). The rules distilled from it are rules 6 to 13 in claude/story-line-rules.md.

How rows get here: "Apply my script edits" (docs/SCRIPT_EDITOR.md) and every REPORT note on a dialogue line (`kind: dialogue` on branch inbox; the report id is the source). After each chapter Tom plays, the session that fixes his reports adds his line edits here in the same push.
