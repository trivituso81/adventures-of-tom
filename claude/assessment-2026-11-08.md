# Game assessment, 2026-11-08 (main at 17f8eed, build tombo11)

Scope: issues and limits NOT already pending in claude/next.md, claude/build-plan.md, claude/ux-audit-builders.md, claude/size-remediation-plan.md or docs/NEXT.md. Method: read those lists, cloned main, ran the game headless on an iPhone-size screen (390 x 844, touch) in portrait and landscape, measured every visible button and text size on the title, map, all eight menu pages, the save box and a 4-member battle, tested with the network cut, read the save, service worker and app-resume code, ran the test suites one at a time. No game files were changed.

Clean results (fact): smoke passed, no page errors on any screen walked, dialogue advances by key and tap, reach_test, rooms_test and tap_test pass.

## Findings

Sev: H = can lose Tom's progress. M = hurts most sessions. L = polish.

| # | Sev | Finding (fact) | Evidence | Recommended fix |

| 1 | H | Saves exist only in the phone's browser storage. There is no backup, export or second copy. The account sync in engine/cloud-save.js only works inside claude.ai, which is retired. | 3 | M | Coming back after 60 seconds away reloads the game to the title screen (deliberate, engine/main.js).
