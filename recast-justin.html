How to do this

Why: Justin has no New York accent and his voice is too light. This page designs a deeper Long Island voice and re-records every line with its own direction.

1. Paste your API key. 2. Press Design 3 options, play all three, press Use this voice on the one with the thickest accent (none right? press it again for 3 more, or edit the description first). 3. Press Bake all and keep the screen on. 4. Play through, re-take any line, then Export and send me the file.

Directions in [square brackets] tell the voice how to act. Edit one if a line misses. Every bracket also carries the accent, which keeps it from fading mid-line.

Voice slots: if your account is full, the old Justin voice is kept (Kenji uses it too). Lines already in the game keep playing.
